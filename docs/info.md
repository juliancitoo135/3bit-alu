# 3-bit Adder

## How it works

This is a 3-bit adder implemented with logic gates (XOR, AND, OR).
It adds two 3-bit numbers (A and B) and produces a 3-bit result plus carry flags.

## How to test

Use the DIP switches to set the values of A and B.
- A = switches 1, 3, 5 (IN0, IN2, IN4)
- B = switches 2, 4, 6 (IN1, IN3, IN5)

The sum appears on the output LEDs and the carry of each bit is also shown.

## Pinout

- Inputs: A0, B0, A1, B1, A2, B2
- Outputs: SUM0, SUM1, SUM2, Carry0, Carry1, Carry2
